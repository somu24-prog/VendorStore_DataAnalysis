# Vendor Store Sales Analysis Dashboard
## Project Overview
This project focuses on analyzing Vendor Store sales data using Excel. The dashboard provides valuable business insights related to sales performance, customer behavior, order trends, gender-based purchasing patterns, age analysis, and state-wise sales distribution.
The main goal of this project is to transform raw sales data into meaningful visual insights that help businesses make better decisions.
## Project Objective
The objective of this project is to:
- Analyze overall sales performance
- Identify top-performing states and sales channels
- Compare purchasing behavior between men and women
- Analyze order trends by age group and gender
- Track monthly sales and order counts
- Understand order delivery status distribution
## Dataset Details
The dataset contains:
- Customer demographics
- Order information
- Sales amount
- Product category
- Order status
- Sales channels
- State and city information
## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Design
## Dashboard Features
### 1. Monthly Sales Analysis
Tracks:
- Total sales amount
- Number of orders per month
### 2. Sales Analysis by Gender
Compares:
- Sales contribution of Men vs Women
### 3. Order Status Analysis
Shows:
- Delivered orders
- Cancelled orders
- Returned orders
- Refunded orders
### 4. Top 5 States by Sales
Identifies:
- Highest revenue-generating states
### 5. Age vs Gender Analysis
Analyzes:
- Purchasing behavior across different age groups
### 6. Orders vs Sales Trend
Displays:
- Relationship between order count and sales amount
 ## Key Insights
- Women customers contributed more sales compared to men.
- Monthly sales trends help identify peak business periods.
- Certain states generated significantly higher revenue.
- Most orders were successfully delivered.
- Adult age groups contributed major sales volume.
## Business Benefits
This dashboard helps businesses to:
- Improve sales strategies
- Understand customer behavior
- Identify profitable regions
- Optimize inventory planning
- Track order performance effectively
